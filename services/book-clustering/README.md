python -m venv .venv && .venv/Scripts/activate     # Windows (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt -r requirements-dev.txt

# خدمة تجميع الكتب (Book Cluster API)

خدمة ويب صغيرة (FastAPI) بتاخد **كتاب جديد** (عنوانه، وموضوعاته لو موجودة) وترجّع **المجموعة الموضوعية** اللى يقع فيها. مبنية على نفس موديل الـClustering فى الـNotebook.

---

## 1. الملفات

| الملف | الوظيفة |
|---|---|
| `clustering_core.py` | قلب الموديل: تنضيف النص، التدريب، التنبؤ، الحفظ والتحميل |
| `train.py` | بيدرّب الموديل على الكتالوج ويحفظه |
| `api.py` | الـAPI نفسه (FastAPI) |
| `requirements.txt` | المكتبات بنسخها المحددة |
| `model/book_clusters.joblib` | الموديل المدرّب (TF-IDF + SVD + KMeans للعربى والإنجليزى) |
| `model/training_report.json` | إعدادات التدريب ونسخ المكتبات ومقاييس الجودة |

## 3. الـEndpoints

| الطريقة | المسار | الوظيفة |
|---|---|---|
| GET | `/health` | حالة الخدمة وتاريخ تدريب الموديل وعدد المجموعات (16) |
| GET | `/clusters` | كل المجموعات بأسمائها وعدد الكتب اللى اتدرّبت عليها |
| POST | `/predict` | مجموعة كتاب واحد |
| POST | `/predict_batch` | مجموعات لحد 500 كتاب فى طلب واحد (النتايج بنفس ترتيب الإدخال) |

### الطلب (`/predict`)
```json
{
  "title": "مبادئ التسويق الحديث",
  "subjects": "التسويق | المستهلك",
  "subject_codes": [12, 40]
}
```
- `title`: **مطلوب** (عربى أو إنجليزى، حتى 500 حرف).
- `subjects` و`subject_codes`: **اختيارى**. لو موجودين الدقة بتبقى أحسن (انظر القسم 5).

### الرد
```json
{
  "language": "ar",
  "cluster": "AR-7",
  "cluster_label": "التسويق / المستهلك / البيع / الاعلان",
  "distance": 0.2944,
  "margin": 0.7377,
  "alternatives": [
    {"cluster": "AR-2", "cluster_label": "اداره / الاداره / الاعمال / المشروعات", "distance": 1.0321},
    {"cluster": "AR-5", "cluster_label": "العامه / مصر / المنظمات / الاداره", "distance": 1.0795}
  ],
  "reason": null
}
```

| الحقل | المعنى |
|---|---|
| `language` | `ar` لو العنوان فيه أى حرف عربى، غير كده `en` |
| `cluster` / `cluster_label` | المجموعة الأقرب واسمها (من أهم 4 كلمات فيها) |
| `distance` | المسافة لمركز المجموعة (أقل = أقرب) |
| `margin` | الفرق بين أقرب مجموعة وتانى أقرب مجموعة. **ده مؤشر الثقة** (انظر القسم 5) |
| `alternatives` | أقرب مجموعتين تانيتين |
| `reason` | `null` عادةً، أو `"no_known_words"` (انظر تحت) |

**لو مفيش ولا كلمة من العنوان معروفة للموديل** (مثلًا كلمات غريبة)، الرد بيبقى `cluster: null` و`reason: "no_known_words"`. ده أحسن من تخمين عشوائى، والبرنامج المستدعى لازم يتعامل مع الحالة دى (مثلًا يخلى الكتاب "بدون تصنيف").

### أمثلة

**curl:**
```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"title": "Principles of Marketing"}'
```

**Python:**
```python
import requests
r = requests.post("http://localhost:8000/predict_batch", json={"books": [
    {"title": "Financial Accounting"},
    {"title": "إدارة الموارد البشرية", "subjects": "الموارد البشرية"},
]})
print(r.json()["results"])
```

### أكواد الأخطاء
- `422`: مدخل غلط (عنوان فاضى أو أطول من 500 حرف، أو `books` فاضية أو أكتر من 500).
- `503`: الموديل مش متحمّل.

## 5. جودة التنبؤ بكتاب جديد (مهم)

جرّبت: دربت الموديل على 80% من الكتب، وتوقعت مجموعة الـ20% الباقية (543 كتاب) كأنهم كتب جديدة.

| الحالة | NMI مع ديوى | Purity |
|---|---|---|
| عنوان + موضوعات + أكواد | 0.323 | 0.665 |
| **عنوان فقط** | **0.239** | **0.602** |
| المرجع (كل الكتب فى مجموعة) | - | 0.481 |

- بالعنوان بس، **72%** من الكتب بتروح لنفس المجموعة اللى كانت هتروحلها لو الموضوعات موجودة.
- **8 كتب من 543 (1.5%)** مكانش فيها ولا كلمة معروفة.
- **الـ`margin` بيقول مين الأكتر موثوقية** (على نفس الـ543 كتاب، بالعنوان فقط):

| `margin` | نسبة الاتفاق مع التنبؤ الكامل |
|---|---|
| أقل من 0.11 | 53% (ثقة ضعيفة) |
| من 0.11 إلى 0.23 | 74% |
| أكبر من 0.23 | 87% (ثقة جيدة) |

الأرقام دى إرشاد مش قاعدة، ومبنية على كتالوج واحد. التوصية: لو `margin` صغير، اعرضى المجموعة كـ"مقترحة" وخلى أمين المكتبة يراجعها.

## 6. حدود وتحذيرات

1. **مفيش ربط بين العربى والإنجليزى:** مجموعة "التسويق" العربى و"marketing" الإنجليزى منفصلتين.
2. **التجميع للاستكشاف مش للدقة العالية:** ديوى نفسه متداخل (أغلب الكتب إدارة واقتصاد)، فالمجموعات متداخلة. لو المطلوب تصنيف دقيق للكتب الجديدة، موديل التصنيف (Classification) أنسب.
3. **نسخة scikit-learn لازم تكون نفسها (1.9.1):** ملف `.joblib` بيتحمّل بس بنفس النسخة اللى اتدرّب بيها. لو النسخة اختلفت، دربى من جديد على السيرفر بـ`train.py`.
4. **أمان:** ملفات `.joblib` هى Pickle، وتحميلها ممكن ينفّذ كود. **حمّلى بس الملفات اللى انتى عملتيها.**
5. **الـAPI مفيهوش تسجيل دخول (Authentication) ولا حد لعدد الطلبات ولا CORS.** لو هيتفتح للإنترنت، ضيفوا حماية قدامه (API key أو Gateway).
6. **الموديل ثابت:** كتب جديدة ما بتغيّرش المجموعات. لتحديثها لازم إعادة تدريب.
7. **مفيش تقييم ببيانات استعارة:** المجموعات بتوصف المحتوى بس، مش الطلب.
