# واجهة الكتاب المفتوح — مكتبة أكاديمية السادات

واجهة جديدة فوق نفس محرك البحث. الواجهة نفسها ملفات جديدة بتتضاف للمشروع، ومفيش سطر اتغير
في `streamlit_app.py` ولا `streamlit_cloud/app.py` ولا `requirements.txt`.

**ملحوظة:** مع الواجهة دي اتضاف للمحرك **توسيع البحث بين اللغتين** (v13): ملف جديد `sams_rag/expansion.py`،
وتعديل في `sams_rag/search.py` و`sams_rag/config.py` (الإعداد `query_expansion`، و`False` بيرجّع سلوك v12 بالظبط).
التقييم بالنماذج الحقيقية: nDCG@10 = 0.897 (كان 0.887)، والأسئلة المختلطة عربي/إنجليزي 0.813 (كانت 0.749)، ومفيش نوع نزل.

## الملفات
```
book_app.py                  ← الصفحة الجديدة (نفس منطق streamlit_app.py: begin → preview → end → serialize)
book_ui/
  __init__.py
  render.py                  ← يجهّز بيانات الإجابة + بطاقة كل كتاب ويبني HTML الكتاب
  theme.py                   ← شكل الصفحة: خلفية المكتبة، الشريط الجانبي الكحلي، سطر السؤال الكريمي
  assets/book.html           ← قالب الكتاب
  assets/book.css            ← تصميم الكتاب والحركات (فتح الغلاف، تقليب الصفحات، الحبر)
  assets/book.js             ← رسم الإجابة والمصادر والبطاقات والقائمة الكاملة
  assets/fonts/              ← الخطوط (أميري، عارف رقعة، IBM Plex Sans Arabic) + رخصتها LICENSES.txt
streamlit_cloud/book_app.py  ← نقطة تشغيل Streamlit Cloud للصفحة الجديدة
book_ui/relevance.py         ← اتنقل لـ sams_rag/listing.py (v16)، عشان موقع Yousef ياخد نفس القايمة
tests/test_book_app.py       ← اختبارات صفحة Streamlit

```

## التشغيل محليًا
انسخ الملفات في جذر المشروع (جنب `streamlit_app.py`) وبعدين:
```
streamlit run book_app.py
```

## الربط بـ Streamlit Community Cloud
1. ارفع الملفات الجديدة على نفس الريبو في GitHub.
2. اعمل App على Streamlit Cloud، وخلي **Main file path** = `streamlit_cloud/book_app.py`.
3. الـ Secrets زي ما هي (`GEMINI_API_KEY`). مفيش مكتبات جديدة.

## إيه اللي بيحصل في الصفحة
- **أول زيارة:** الكتاب الكحلي المقفول بيتفتح على صفحة العنوان، وبعدها يظهر الكتاب المفتوح.
- **وهو بيدوّر:** عنوان السؤال بيتكتب، والكتب اللي البحث لقاها (`engine.preview`) بتظهر في الفهرس، والصفحات بتتقلب لحد ما Gemini يخلص.
- **الإجابة:** صفحة بتتقلب، والإجابة بتظهر سطر سطر بأرقام المصادر [S#]. الضغط على أي رقم أو أي كتاب في الفهرس بيعرض بطاقته، و"كل حقول البطاقة" بيفتح الـ 22 حقل.
- **ترتيب الكتب:** Gemini ممكن يكتب الكتب بأي ترتيب، فالكتاب بيعرض قائمة الإجابة وفهرس المصادر بترتيب البحث (S1 الأقرب للسؤال، بعده S2…) ويعيد ترقيمها. ده في العرض بس، والنص اللي Gemini كتبه مش بيتغير.
- **كل الكتب المطابقة:** الصفحة بتتقلب على القائمة الكاملة، وأي كتاب فيها بيفتح بطاقته الكاملة.
- **الأسئلة السابقة:** بتظهر كشرائط على جنب الكتاب، والضغط عليها يرجّع إجابتها.
- **الفلاتر والأمثلة** في الشريط الجانبي بتشتغل بنفس طريقة الصفحة القديمة.

## الخطوط (شغالة على كل الأجهزة)
الخطوط محطوطة جوه المشروع نفسه (`book_ui/assets/fonts/`) ومش بتتحمّل من Google Fonts،
فبتظهر صح على أي جهاز وأي متصفح، حتى لو الجهاز مافيهوش خطوط عربي، أو الشبكة حاجبة Google.
- الخطوط بتتبعت مع أول عرض للكتاب في كل جلسة بس (حوالي 575KB)، والكتاب بيركّبها في الصفحة كلها
  (الشريط الجانبي كمان). العروض اللي بعدها بتستخدمها من الصفحة، فبتفضل خفيفة.
- لو حصل أي سبب منع ده، الصفحة بتستخدم خطوط النظام العربية (Noto / Geeza Pro / Traditional Arabic) بدل ما تبوظ.
- الخطوط الثلاثة رخصتها SIL Open Font License 1.1 (مجانية ومسموح توزيعها مع المشروع).

## قائمة "الكتب ذات الصلة"
لما السؤال عن موضوع (من غير فلتر مؤلف)، الصفحة بتخلي المحرك يجيب أقرب 100 كتاب (بدل 30). الواجهة بتدّي كل كتاب منهم درجة صلة
من 0 لـ 1 بنموذج إعادة الترتيب بتاع المحرك نفسه، وبتعرض اللي درجته 0.2 أو أكتر بس (والكتب المذكورة في الرد دايمًا).
- أول 20 كتاب من ترتيب المحرك بيفضلوا دايمًا (`BOOK_KEEP_TOP`)، والباقي بيظهر لو درجته وصلت للحد. الرقم 20 اتقاس بـ `scripts/keep_top_study.py`: المراكز 11–15 و16–20 فيها نسبة كتب صح متقاربة (30% و26%)، وبعد 20 الإفادة بتقل للنص، ودرجة الصلة لوحدها بتسيب 45% بس من الكتب الصح.
- الدرجة بتتحسب مرتين: مرة بكلام السؤال ومرة بصياغة البحث، وبيتاخد الأعلى (عشان الكتب العربي في سؤال إنجليزي والعكس).
- تغيير الحد: `BOOK_MIN_RELEVANCE = "0.3"` في Secrets (أعلى = قائمة أقصر وأدق).
- لظبط الحد: `BOOK_SHOW_SCORES = "1"` بيعرض درجة كل كتاب جنب السنة في القائمة.
- تغيير عدد الكتب اللي بيتفحص: `BOOK_LIST_LIMIT = "150"` (أكبر = قائمة أشمل بس أبطأ شوية).
- قوائم المؤلف (كل الكتب المطابقة) مش بتتأثر.
