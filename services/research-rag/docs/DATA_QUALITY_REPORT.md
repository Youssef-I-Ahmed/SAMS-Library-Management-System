## What is NOT done automatically
* Records are not deleted or merged. Duplicates are reported, not removed.
* Similar supervisor names are not merged; a human decides (see `data/processed/supervisor_candidates.csv`).
* Invalid years are flagged, not guessed.

## Dataset limitation
The dataset is bibliographic metadata only (title, students, supervisors, year, call number, extent, dimension, subject). It contains **no abstracts, findings, methodology or full text**; the system therefore cannot answer such questions (see EVIDENCE_POLICY.md). It also contains student names — keep the repository private or exclude `data/`.
