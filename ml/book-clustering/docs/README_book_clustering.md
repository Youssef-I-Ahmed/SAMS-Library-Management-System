# تجميع كتب المكتبة حسب الموضوع (Book Topic Clustering)

سكريبت بايثون `book_clustering.py` بيقرأ كتالوج كتب المكتبة (`SAMS_Books_Merged_Book_Names_Corrected.xlsx`)، ويجمّع الكتب المتشابهة فى مجموعات موضوعية من غير تصنيف جاهز (Unsupervised Learning)، ويكشف المواضيع الضعيفة فى المجموعة.

---

## 1. الهدف

- اكتشاف المواضيع الطبيعية الموجودة فى المكتبة.
- إعطاء كل مجموعة اسم مقروء من أهم كلماتها.
- تحديد **المواضيع الضعيفة** (كتب قليلة، نسخ قليلة، كتب قديمة).
- قياس مدى توافق المجموعات مع تصنيف ديوى الحقيقى.

> الـClustering ملوش "Accuracy" لأنه مفيهوش إجابة صح. عشان كده بنقيس **التوافق مع تصنيف ديوى** (أول رقمين من `CALL_NUM`) بمقاييس NMI وARI وPurity.

## 4. خطوات السكريبت

1. **التنضيف** (`load_and_clean`)
   - تحويل `NA` لقيم ناقصة.
   - شيل سنوات النشر الغلط (أقل من 1900 أو أكبر من 2026).
   - حذف العناوين المكررة.
   - تحديد لغة العنوان (عربى / إنجليزى).
   - استخراج رقم ديوى من `CALL_NUM` (أول 3 أرقام).
2. **تجهيز النص** (`normalize_text` و`light_stem`)
   - توحيد الحروف العربى (أ إ آ ← ا، ى ← ي، ة ← ه) وشيل التشكيل وعلامات الترقيم والأرقام.
   - شيل كلمات الربط (Stop Words).
   - تقطيع خفيف للكلمات (شيل "ال" واللواحق) عشان "الإدارة" و"إدارة" يتعاملوا ككلمة واحدة.
3. **بناء الخصائص** (TF-IDF)
   - النص = العنوان + `SUBJECTS` **3 مرات** + `SUBJECT_CODES` **مرتين**.
   - Unigrams وBigrams.
4. **تقليل الأبعاد**: `TruncatedSVD` إلى 30 بُعد ثم Normalize.
5. **التجميع**: `KMeans` لكل لغة لوحدها (العربى والإنجليزى).
6. **تسمية المجموعات**: أهم 4 كلمات من نص غير مقطّع عشان الأسماء تبقى مقروءة.
7. **التقييم**: مقارنة المجموعات بتصنيف ديوى (NMI وARI وPurity)، ومرجع Supervised بـLinearSVC.
8. **تحليل الضعف**: جدول لكل مجموعة (انظر القسم 6).
9. **الإخراج**: ملف Excel وثلاث رسومات.

## 6. تعريف "الموضوع الضعيف"

لكل مجموعة بنحسب:

| المقياس | المعنى |
|---|---|
| `books` | عدد الكتب |
| `total_copies` / `avg_copies` | مجموع ومتوسط عدد النسخ |
| `median_year` | وسيط سنة النشر |
| `pct_old` | نسبة الكتب الأقدم من 10 سنين |
| `pct_single_copy` | نسبة الكتب اللى ليها نسخة واحدة |

وبنحط 3 علامات (Flags)، كل واحدة بتتفعّل لو المجموعة فى أسوأ ربع:

- `flag_few_books`: عدد كتب قليل.
- `flag_old`: نسبة كتب قديمة عالية.
- `flag_low_copies`: متوسط نسخ منخفض.

`weakness_score` = مجموع العلامات (من 0 إلى 3). كل ما زاد كان الموضوع أضعف.

> التعريف **نسبى** بين المجموعات. ولو الأكاديمية ليها تعريف تانى للضعف يتعدّل فى دالة `summarize`.

## 7. النتايج على الكتالوج الحالى

- **حجم الداتا**: 2,842 صف ← **2,717 كتاب** بعد حذف المكرر (1,890 عربى و827 إنجليزى).
- **المجموعات**: 16 (10 عربى + 6 إنجليزى).
- **Silhouette**: 0.176 (عربى) و0.139 (إنجليزى).

**التوافق مع تصنيف ديوى** (2,713 كتاب):

| المقياس | قبل التحسين | بعد التحسين |
|---|---|---|
| NMI | 0.274 | **0.307** |
| ARI | 0.049 | **0.121** |
| Purity | 0.645 | **0.680** |

المرجع: لو كل الكتب فى مجموعة واحدة، الـPurity = 0.481.

**مرجع Supervised** (توقع تصنيف ديوى بـLinearSVC و5-fold CV):

| المدخل | الدقة |
|---|---|
| العنوان فقط | 76.0% |
| العنوان + الموضوعات | 85.3% |

الرقم الأول هو الأنسب للكتب الجديدة اللى لسه ملهاش موضوعات.

## 8. القرارات اللى اتاخدت (وليه)

| القرار | السبب |
|---|---|
| تجميع كل لغة لوحدها | لما اتجمّعت العربى والإنجليزى مع بعض، المجموعات انقسمت بحسب اللغة مش الموضوع |
| وزن الموضوعات 3× العنوان | العنوان لوحده ضعيف (NMI = 0.12 بالعنوان فقط) |
| إضافة `SUBJECT_CODES` بوزن 2 | رفعت التوافق مع ديوى |
| SVD = 30 بُعد | أحسن من 100 أو 200 بُعد، بيقلل التشويش |
| تثبيت k | زيادة عدد المجموعات بترفع Purity تلقائيًا (تضليل) |

## 9. الحدود والتحذيرات

- **جودة التجميع متواضعة**: ديوى نفسه متداخل (أغلب الكتب 65x إدارة و33x اقتصاد)، وحوالى 25 تجربة وصلت لنفس السقف تقريبًا (NMI ≈ 0.30). المجموعات مناسبة للاستكشاف والتحليل، مش حدود دقيقة بين المواضيع.
- **مفيش ربط بين اللغتين**: مجموعة "الإدارة" العربى ومجموعة "management" الإنجليزى منفصلتين. الحل محتاج Embeddings متعددة اللغات (مثل `paraphrase-multilingual-MiniLM`) وده بيحتاج تحميل موديل من الإنترنت.
- **المكتبة قديمة بالكامل تقريبًا**: وسيط سنة النشر 2008، فمقياس `pct_old` مرتفع فى كل المجموعات، واستخدام ربع الأسوأ بيميّز بينهم نسبيًا بس.
- **عدد النسخ** لقطة ثابتة، مش سجل استعارة. لما بيانات الاستعارة تتجمع يمكن ربط الضعف بالطلب الفعلى.
- **قيم غير منطقية** فى الداتا: سنة نشر `0` ونسخ `0` (كتاب واحد) و111 نسخة (كتاب واحد)، ولازم تتراجع.

## 10. تطوير مقترح

1. Embeddings متعددة اللغات لربط العربى بالإنجليزى فى مجموعات موحدة.
2. ربط المجموعات ببيانات الاستعارة لما تتجمع (الطلب لكل موضوع بالشهر).
3. تطبيق Streamlit لعرض المجموعات والمواضيع الضعيفة.
4. موديل تصنيف مستقل (Naive Bayes وLogistic Regression وLinearSVC) للكتب الجديدة.
